# AGENTS.md

## Sean Ali / Hypnotic Meditations Design System

Before editing any page, read this file and obey it.

You are not designing from scratch.
You are implementing Sean Ali’s funnel style.

## Core Style

Build pages that feel like:

- premium direct-response funnel
- Shopify conversion layout
- Lovable/Base44-level polish
- clean mobile-first landing page
- spiritual wealth brand
- simple, sharp, high-converting

Do not make pages feel like:

- generic SaaS
- boring template
- corporate website
- tiny text startup landing page
- overdesigned AI art page
- cluttered guru funnel
- cheap ClickFunnels page

## Visual Taste

Use:

- black / deep navy / dark purple backgrounds
- gold, white, soft violet accents
- strong contrast
- big readable headlines
- generous spacing
- rounded premium cards
- clean shadows/glow only when tasteful
- mobile-first one-column structure
- large CTA buttons
- simple trust badges
- product mockup/image area near the hero

Avoid:

- tiny fonts
- weak gray text
- thin buttons
- too many gradients
- cheesy animations
- emoji spam
- fake luxury clutter
- random icon grids
- desktop-first layouts

## Copy Feel

Voice must sound like Sean:

- blunt
- simple
- human
- direct
- short lines
- no corporate tone
- no robotic phrasing
- no hype without substance
- no long theory

Use language around:

- freedom
- dream life
- success mindset
- subconscious reprogramming
- identity shift
- nervous system reset
- money blocks
- inner programming
- 7-minute reset
- before sleep
- press play

Do not overuse:

- “money stress gets loud at night”
- “low vibration”
- “manifest harder”
- fluffy spiritual wording
- fake science claims

## Page Structure

Default funnel page structure:

1. Urgency or trust bar
2. Hero with big promise
3. Product/image/mockup
4. CTA above the fold
5. Simple proof
6. Problem section
7. Mechanism section
8. What they get
9. Testimonials/social proof
10. Offer stack
11. Guarantee or reassurance
12. Final CTA

Every section must earn its place.

## Conversion Rules

- One main CTA per page.
- CTA must be obvious.
- CTA text should be action-based.
- Hero must explain the offer in 5 seconds.
- Mobile must look perfect.
- Above the fold must not feel empty.
- No giant walls of text.
- Every section should move the user closer to action.
- Preserve existing links unless asked to change them.
- Preserve existing tracking/scripts/forms unless asked to remove them.

## Mobile Rules

Design mobile first.

- headline readable without zoom
- buttons full-width or near full-width
- no horizontal scroll
- no cramped cards
- no tiny testimonial text
- no clipped videos/images
- spacing should feel premium, not bloated

## Coding Rules

When editing:

- make the smallest clean change that improves the page
- do not break existing functionality
- do not remove scripts, forms, embeds, pixels, or links unless instructed
- keep code clean and easy to edit
- use semantic HTML where possible
- keep CSS organized by section
- avoid unnecessary libraries

## Default Instruction

If the user says “make this page better,” interpret it as:

Improve the page using Sean Ali’s premium direct-response funnel style:
black/gold/purple, mobile-first, simple, high-converting, emotionally clear, polished like Lovable/Base44, but grounded like a real sales page.
