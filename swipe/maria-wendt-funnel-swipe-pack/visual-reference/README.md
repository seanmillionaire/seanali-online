## Fidelity rules for the Money Flow implementation

The written swipe analysis should inform conversion mechanics, but the screenshots are the visual ground truth. The single Money Flow offer should follow Page 1: white top section, product first, magenta headline, green rectangular purchase action, proof immediately below the hero, then one clear inclusions card. The Money Mind Stack should follow Page 2: product collection dominates the first viewport, product groups are organized around buyer intent, and the long stack uses alternating pale-blue and pale-pink sections with repeated direct-checkout buttons.
